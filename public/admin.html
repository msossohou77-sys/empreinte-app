    Aperçu

    Génération de l'aperçu…

    Personnalise la page publique vue par tes utilisateurs finaux.

    Reçois une notification (requête POST) sur ton propre système à chaque document généré via ce modèle — utile pour connecter Empreinte à un outil tiers (CRM, billetterie, Zapier-like...).

    Exemple de charge utile envoyée en POST (JSON) : 
    {
  "event": "submission.created",
  "templateId": "...", "templateName": "...",
  "submissionId": "...", "values": { "Nom": "Awa Koffi" },
  "downloadUrls": { "png": "...", "jpeg": "...", "pdf": "..." },
  "verifyUrl": "...", "createdAt": "..."
}

    Pour générer des documents depuis un système externe sans passer par le formulaire public, utilise ta clé API (visible dans la barre latérale) avec l'API publique documentée dans le README du projet (POST /api/v1/templates/{id}/generate).
